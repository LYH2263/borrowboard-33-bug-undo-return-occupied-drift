# Borrowboard · 邻里借用

上架 → 借出通过 → 归还；单物件同时仅一笔在借，含逾期判定。

归还可撤销：仅借还记录中**最近一笔已还**可撤，须填撤销原因。确认时若该物归还后已被别人借出：

- `fail`（默认）：整单失败保持现况，可借栏/在借栏/借还记录均不变；
- `bump`：挤掉归还后的新借（标记 cancelled），原笔回到在借，处置写入借还记录。

撤销后再借出仍走单物互斥；逾期判定只在读取时计算，撤销、新借、逾期扫对每笔只留一种 loan 状态。
